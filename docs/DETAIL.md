# Skill Forge

在左侧栏加一个「技能工坊」入口，点开是一个主区面板，用来管这台机器上的 skill。

## 面板里能做什么

**列表** — 当前工作区能看到的全部 skill（`~/.dsh/skills`、`~/.agents/skills`、项目级、插件自带的都算），显示名字、两行描述、以及是否校验过。搜索框按名字和描述过滤。

**概览** — 选中一个 skill 后的第一屏：名字、来源目录、磁盘路径、行数与字节数、description、什么时候用。

**SKILL.md** — 原文，等宽字体，换行不横向滚动。

**校验** — 点一下跑一遍格式检查，结果是错误和提醒两档：

- 错误：frontmatter 缺失或没闭合、`name` 不是 kebab-case、`name` 与目录名不一致、未知 frontmatter 字段、`description` 超过 1024 字符、正文超过 500 行、正文少于 100 字符。
- 提醒：`description` 短于 30 字符、`description` 里看不出「什么时候用」、SKILL.md 引用了不存在的 `references/` 或 `scripts/` 文件。

**文件** — skill 目录下的文件与子目录清单。

**新建 skill** — 填名字和 description，选一个根目录（`~/.dsh/skills` 或 `~/.agents/skills`），生成一份带注释的 SKILL.md 骨架。

## 限制

- 新建只会写到上面那两个用户级目录，不写项目目录，也不覆盖已存在的目录。
- 面板不能编辑 skill：改了要落到磁盘、还要让注册表重新扫描，这一版没做。
- 校验只查能客观判定的格式问题，不判断内容写得好不好。
- 插件的 skill 没有磁盘目录时，校验和文件两页会说明无法进行。
